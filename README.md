# SE237 Week 2 Coding Practice Lab

Java solutions for the SE 237 Object Oriented Programming Week 2 Coding Practice Lab.

## Exercises

- Exercise 1 — Object and Reference
- Exercise 2 — Protect an Object in the Constructor
- Exercise 3 — Protect an Internal List
- Exercise 4 — A Query Method Without Side Effects
- Exercise 5 — Dependency vs Association
- Exercise 6 — Give Each Class One Clear Job

## Requirements

- Java 21 or a compatible JDK

## Running an exercise

Run commands from the repository root.

```bash
javac Exercise1/*.java
java Exercise1.Main
```

Replace `Exercise1` with the exercise you want to run.
